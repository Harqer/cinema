# Movie Expert Agent — Blueprint

The Movie Expert is a playbook-based prebuilt agent that answers a wide range
of movie-related questions. This document captures its architecture, tools,
and how to extend it for the Agentic Cinema full-production pipeline.

---

## What It Does

The Movie Expert agent handles two core query types:

| Query Type | Example | Data Source |
|---|---|---|
| **Plot & narrative** | "Tell me about Avatar" | `cymbal-movie-plots` Data Store (Wikipedia summaries) |
| **Structured metadata** | "How much profit did Avatar make?" | `bq-search` OpenAPI tool → BigQuery |
| **Cross-filtered queries** | "Highest-earning non-English film in December 2009?" | `bq-search` with SQL filters |

## Tools

### `cymbal-movie-plots` (Data Store Tool)

- **Type:** Agent Builder Data Store Tool (Steering)
- **Source:** Cloud Storage bucket → Wikipedia movie plot summaries
- **Auto-created:** Yes, when importing the prebuilt agent with dependent resources
- **Use:** Unstructured narrative queries ("Tell me about", "What happens in")

### `bq-search` (OpenAPI Tool)

- **Type:** OpenAPI tool → BigQuery REST API
- **Auth:** Service Account (BigQuery Job User + Data Viewer roles)
- **Input:** SQL query generated by the agent
- **Output:** JSON query results
- **Tables:**
  - `Movies.movies_data` — title, revenue, budget, release_date, original_language, genres
  - `Movies.credits` — cast, crew per movie

## Setup Instructions

### 1. Import the Prebuilt Agent

1. Go to [Agent Builder](https://cloud.google.com/dialogflow/cx/docs/concept/playbook/prebuilt)
2. Import the **Movie Expert** prebuilt agent
3. Leave **Create dependent resources** ✓ checked
   - This auto-creates the BigQuery `Movies` dataset with `movies_data` and `credits` tables
   - This auto-creates the `Movie Expert-data-store` with Wikipedia plot summaries

### 2. Configure `bq-search` Authentication

```bash
# Create a service account
gcloud iam service-accounts create movie-expert-agent \
  --display-name="Movie Expert Agent"

# Grant BigQuery permissions
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:movie-expert-agent@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/bigquery.jobUser"

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:movie-expert-agent@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/bigquery.dataViewer"
```

Then set this service account in the `bq-search` tool authentication settings
in Agent Builder under **Tools → bq-search → Authentication**.

### 3. Test

Use the built-in test console in Agent Builder:
- "Tell me about The Godfather" — should pull plot from Data Store
- "What was the budget of Inception?" — should query BigQuery
- "What was the highest-grossing film in July 2010?" — should filter by date

## BigQuery SQL Patterns

The agent auto-generates SQL. Here are the patterns it uses:

```sql
-- Single film lookup
SELECT title, revenue, budget, (revenue - budget) AS profit
FROM `project.Movies.movies_data`
WHERE LOWER(title) = 'avatar'
LIMIT 1;

-- Cross-filtered (language + date range)
SELECT title, revenue
FROM `project.Movies.movies_data`
WHERE original_language != 'en'
  AND release_date BETWEEN '2009-12-01' AND '2009-12-31'
ORDER BY revenue DESC
LIMIT 1;

-- Join with credits
SELECT m.title, c.cast
FROM `project.Movies.movies_data` m
JOIN `project.Movies.credits` c ON m.id = c.movie_id
WHERE LOWER(m.title) = 'the dark knight'
LIMIT 1;
```

## Extending for Full Production

The Movie Expert's tool pattern is the foundation for the full Agentic Cinema
pipeline. Extensions:

### Add Parallel Web Search for Live Data

The Movie Expert only knows historical data in BigQuery and Wikipedia.
To answer questions about current box office, recent releases, or trending
films, add a Parallel tool:

```python
from google.genai import types

# Add to agent tools list alongside cymbal-movie-plots and bq-search
parallel_tool = types.Tool(
    parallel_ai_search=types.ToolParallelAiSearch(
        custom_configs={
            "mode": "basic",
            "max_results": 5,
            "source_policy": {
                "include_domains": ["boxofficemojo.com", "imdb.com", "deadline.com"]
            }
        }
    )
)
```

### Add Google Maps for Location Context

For questions like "Where was Avatar filmed?" or "What studios are near
Vancouver for an Avatar-scale production?":

```python
from google.genai.types import GoogleMaps, Tool

maps_tool = Tool(google_maps=GoogleMaps())
```

### Add Book-to-Script RAG

To answer questions about how a specific book should be adapted, wire in the
BigQuery Vector Store containing book chunks:

```python
retriever = bq_store.as_retriever()
# Use as context in a RetrievalQA chain alongside the Movie Expert
```
