# Grounding Reference — All Sources

Agentic Cinema uses four grounding mechanisms. This doc is the definitive
reference for each, when to use it, and how to wire it in code.

---

## Overview

| Source | Best For | Latency | Cost Driver |
|---|---|---|---|
| **Parallel Web Search** | Live web, film research, fact checks | Medium | Parallel query fees |
| **Google Maps** | Location scouting, routing between shoot sites | Medium | Maps query fees |
| **Agent Search (Data Store)** | Wikipedia plots, internal doc corpus | Low | Agent Search queries |
| **BigQuery (`bq-search`)** | Structured movie metadata (revenue, cast, budget) | Very low | BQ slot usage |

---

## 1. Parallel Web Search

Live LLM-optimized web index. Use for anything requiring current web data.

```python
from google import genai
from google.genai import types

client = genai.Client()

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Who are the top cinematographers working in sci-fi right now?",
    config=types.GenerateContentConfig(
        tools=[
            types.Tool(
                parallel_ai_search=types.ToolParallelAiSearch(
                    # api_key="..." if using BYOK; omit for Marketplace
                    custom_configs={
                        "mode": "advanced",        # "basic" | "advanced"
                        "max_results": 10,
                        "location": "us",          # ISO 3166-1 alpha-2
                        "source_policy": {
                            "include_domains": ["variety.com", "imdb.com"],
                        },
                    }
                )
            )
        ],
    ),
)
print(response.text)
```

Full details: [`docs/PARALLEL_INTEGRATION.md`](PARALLEL_INTEGRATION.md)

## 2. Google Maps Grounding

Real-world place data — locations, directions, routing between shoot days,
place properties (hours, accessibility, parking).

### Basic place search

```python
from google.genai.types import GoogleMaps, Tool, GenerateContentConfig, ToolConfig, RetrievalConfig, LatLng

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Find film-friendly warehouses and industrial spaces near downtown Los Angeles.",
    config=GenerateContentConfig(
        tools=[Tool(google_maps=GoogleMaps())],
        tool_config=ToolConfig(
            retrieval_config=RetrievalConfig(
                lat_lng=LatLng(latitude=34.0522, longitude=-118.2437),  # LA
                language_code="en_US",
            ),
        ),
    ),
)
print(response.text)
# groundingMetadata.groundingChunks contains place URIs, titles, placeIds
```

### Route planning between shoot locations

```python
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="""
    Plan a 3-day shoot schedule. Day 1: Warner Bros. Burbank.
    Day 2: Vasquez Rocks, Agua Dulce.
    Day 3: El Matador Beach, Malibu.
    Estimate drive times and find fuel stops en route.
    """,
    config=GenerateContentConfig(
        tools=[Tool(google_maps=GoogleMaps())],
        # routing grounding type is enabled automatically for directions queries
    ),
)
```

### Sourcing requirements

When displaying Maps results to end users you **must** attribute each source to
Google Maps immediately after the generated content. Display the `title` and
link to the `uri` from `groundingChunks`. See the
[attribution guidelines](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-maps#google-maps-attribution-guidelines).

## 3. Agent Search Data Store (Movie Plots + Documents)

A managed, zero-config RAG data store. The prebuilt Movie Expert agent uses
two data stores:

| Data Store | Contents | Tool Name |
|---|---|---|
| `Movie Expert-data-store` | Wikipedia movie plot summaries | `cymbal-movie-plots` |
| Custom book corpus | Ingested book chapters for adaptation | Custom Data Store tool |

### Creating a Data Store tool in Agent Builder

1. Go to **Agent Builder → Data Stores → Create**
2. Upload PDFs, text files, or point to a Cloud Storage bucket
3. Add the data store as a **Data Store tool** in your playbook/agent

### Using Agent Search via the SDK

```python
# Agent Builder data stores are accessed through the Agent Builder API
# or configured as tools in the Agent Builder UI.
# For custom RAG over your own documents, use BigQueryVectorStore (see below).
```

## 4. BigQuery `bq-search` (Structured Movie Metadata)

For precise queries against the movies database (revenue, budget, language,
release date, cast). The `bq-search` tool is an OpenAPI tool in Agent Builder
that takes a SQL query generated by the agent and executes it against BigQuery.

### Schema

```sql
-- movies_data table
SELECT title, revenue, budget, release_date, original_language, genres
FROM `project.Movies.movies_data`
WHERE release_date BETWEEN '2009-12-01' AND '2009-12-31'
  AND original_language != 'en'
ORDER BY revenue DESC
LIMIT 1;

-- credits table
SELECT movie_id, cast, crew
FROM `project.Movies.credits`
WHERE movie_id = 19995;  -- Avatar
```

### Authentication

The `bq-search` tool requires a service account with these roles:

```bash
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:your-sa@project.iam.gserviceaccount.com" \
  --role="roles/bigquery.jobUser"

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:your-sa@project.iam.gserviceaccount.com" \
  --role="roles/bigquery.dataViewer"
```

Then configure [Service Account authentication](https://docs.cloud.google.com/dialogflow/cx/docs/concept/playbook/tool#openapi_tool_api_authentication)
in Agent Builder for the `bq-search` tool.

## 5. RAG over Book/Script Corpus (BigQuery Vector Search)

For semantic search over the ingested book chapters and script drafts.

```python
from langchain_google_community import BigQueryVectorStore, VertexFSVectorStore
from langchain_google_vertexai import VertexAIEmbeddings
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import PyPDFLoader

# 1. Embed the book
embedding_model = VertexAIEmbeddings(model_name="text-embedding-005", project=PROJECT_ID)

loader = PyPDFLoader("book.pdf")
documents = loader.load()

splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=50)
chunks = splitter.split_documents(documents)

# 2. Store in BigQuery (prototype — no infra required)
bq_store = BigQueryVectorStore(
    project_id=PROJECT_ID,
    location=LOCATION,
    dataset_name="cinema_production",
    table_name="book_chunks",
    embedding=embedding_model,
)
bq_store.add_documents(chunks)

# 3. Semantic search
results = bq_store.similarity_search("What motivates the antagonist in chapter 3?")

# 4. Upgrade to Feature Store for low-latency production serving
vertex_fs = bq_store.to_vertex_fs_vector_store()
vertex_fs.sync_data()   # ~20 min first time; thereafter use cron_schedule
retriever = vertex_fs.as_retriever()
```

## Combined Grounding Example

The Research Agent uses multiple grounding sources in a single pipeline:

```python
def research_scene(
    scene_description: str,
    location_hint: str,
    lat: float,
    lng: float,
) -> dict:
    """
    For a given scene, returns:
    - Comparable film references (Parallel)
    - Real-world location options (Maps)
    - Related plot context from corpus (Vector Store)
    """
    # 1. Parallel: find comparable scenes in cinema history
    web_answer, web_sources = research_with_parallel(
        query=f"Iconic film scenes similar to: {scene_description}",
        mode="basic",
        include_domains=["imdb.com", "criterion.com", "rogerebert.com"],
    )

    # 2. Maps: find real locations
    maps_response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=f"Find filming locations for: {scene_description} near {location_hint}",
        config=GenerateContentConfig(
            tools=[Tool(google_maps=GoogleMaps())],
            tool_config=ToolConfig(
                retrieval_config=RetrievalConfig(
                    lat_lng=LatLng(latitude=lat, longitude=lng),
                )
            ),
        ),
    )

    # 3. Vector Store: retrieve relevant book passages
    book_context = bq_store.similarity_search(scene_description, k=3)

    return {
        "film_references": web_answer,
        "film_sources": web_sources,
        "location_suggestions": maps_response.text,
        "book_context": [doc.page_content for doc in book_context],
    }
```
